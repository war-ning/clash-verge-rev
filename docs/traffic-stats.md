# 历史流量统计

## 查询与展示

- 默认按目标或完整进程身份汇总；组合明细保留策略组和进程字段。
- 策略组多选、名称/路径搜索在排名截断前执行。上行/下行/合计同时决定排名、图表和占比。
- 页面默认显示前 50 个普通条目；未识别、未归因及旧历史合并项独立保留。可查看全部匹配项。
- 导出全部已保存的匹配记录，并保存查询条件、指标口径及完整性警告；读写失败时不导出不完整文件。
- 时间轴补齐至当前时刻，无采样的桶显示斜纹。一天内部分小时有样本不代表全天连续采集。
- 当前为手动刷新快照。统计范围包含内核处理的直连流量，不代表服务商计费流量。

## 采集与身份

- 启动、重连、停采恢复和清空后首帧只建立基线，不重复计入活动连接历史累计字节。
- 持续会话按连接差值累计；新连接计入该连接累计值。未能分配到连接的全局增量记为未归因。
- 进程优先使用内核提供的完整路径作为身份，否则使用进程名；不根据同名可执行文件猜测软件名称。
- 缺少字段仅替换缺少的字段，保留其他已知信息。关闭进程记录同时停止在域名明细中保存进程信息，不删除已有历史。
- 停采前保存待写增量；写入失败保留待写数据重试并提示。清空失败返回错误。
- 保存完整小时聚合，不在落盘时销毁长尾明细；Top N 仅影响查询结果。

## 旧数据与精度边界

- v3 历史继续读取；缺少新字段采用默认值。不支持的更早版本跳过并提示；当前日文件需要替换时先备份。
- 旧数据中已合并的明细及未保存的进程路径无法恢复。
- 一秒活动连接快照无法还原采样之间结束的短连接及尾部流量归属，重新建立基线期间也不追溯历史。
- 现有 v3 文件使用本地日期和小时，同一天内改变系统时区仍可能影响历史时间解释。
